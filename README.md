
# UNIX Shell Emulator

Эмулятор командной строки UNIX с виртуальной файловой системой (VFS), загружаемой из XML-файла, и поддержкой пакетирования команд через стартовые скрипты.

---

Данный проект представляет собой учебный CLI-эмулятор окружения UNIX, написанный на **C++20**. Эмулятор интерпретирует основные команды файловой системы и системные утилиты, взаимодействуя с изолированной виртуальной файловой системой (VFS) в оперативной памяти.

### Основные возможности
* **Интерпретация команд UNIX:** поддержка базовой навигации, чтения и создания файлов.
* **Виртуальная Файловая Система (VFS):** иерархическая структура файлов и директорий, считываемая из XML-конфигурации при старте.
* **Декодирование данных:** поддержка бинарных/закодированных файлов в формате Base64 прямо в XML.
* **Пакетный режим:** возможность автоматического выполнения сценариев из текстового файла (`--script`).

---

### Требования к окружению
* Компилятор C++ с поддержкой стандарта **C++17** или новее (`MSVC`, `GCC`, `Clang`).
* Опционально: `git`.

### Сборка проекта

#### Windows (MSVC Developer Command Prompt):
cl /EHsc /std:c++17 /Fe:emulator.exe main.cpp

---

Запуск эмулятора осуществляется через командную строку с обязательным указанием пути к файлу виртуальной файловой системы.

### Флаги командной строки

| Длинный флаг | Короткий флаг | Аргумент | Описание |
| --vfs      | -v          | <path> | **Обязательный.** Путь к XML-файлу VFS 
| --script   | -s          | <path> | *Опционально.* Путь к стартовому скрипту с командами 

---

## Поддерживаемые команды

| Команда   | Синтаксис                  | Описание |
| ls        | ls [path]                  | Выводит содержимое директории (или имя файла). |
| cd        | cd [path]                  | Изменяет текущую рабочую директорию VFS. |
| cat       | cat <file1> [file2 ...]    | Выводит содержимое одного или нескольких файлов. |
| touch     | touch <file1> [file2 ...]  | Создает один или несколько пустых файлов в VFS. |
| who       | who                        | Выводит имя текущего пользователя системы. |
| date      | date                       | Выводит текущие дату и время в формате UNIX. |
| conf-dump | conf-dump                  | Выводит текущие параметры конфигурации эмулятора. |
| exit      | exit                       | Завершает работу эмулятора. |

---

## Формат файла VFS (`vfs.xml`)

Виртуальная файловая система описывается с помощью XML-тегов <dir> и <file>. Файлы могут содержать атрибут encoding="base64".
